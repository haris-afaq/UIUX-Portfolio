Create a modern, premium, fully interactive, multi-page personal portfolio website for a professional who specializes in both **UI/UX Design** and **UI/UX Design**.

The website should feel like a combination of a high-end digital product studio and a personal creative portfolio. Use a clean, modern, visually impressive interface with strong typography, smooth animations, micro-interactions, responsive layouts, and a premium dark-first visual style.

* Creative

## Visual Design Direction

Use:

* Premium dark background
* High contrast typography
* Modern sans-serif typography
* Large bold headlines
* Clean spacing
* Rounded cards
* Glassmorphism used carefully
* Subtle gradients
* Soft borders
* Minimal shadows
* Abstract 3D or geometric visual elements
* Code-inspired design details

The visual style should feel like a combination of:

**Premium SaaS website + Creative Developer Portfolio + Modern UI/UX Design Agency**

Avoid:

* Generic templates
* Excessive gradients
* Overly colorful interfaces
* Cluttered layouts
* Too many animations
* Generic stock photography

## Interaction & Animation

Make the website highly interactive with:

* Smooth page transitions
* Scroll-triggered animations
* Parallax effects
* Hover interactions
* Magnetic buttons
* Animated project cards
* Cursor interactions
* Text reveal animations
* Image reveal animations
* Animated skill bars
* Interactive timeline
* Smooth filtering transitions
* Horizontal scrolling project sections
* Interactive case study galleries
* Micro-interactions on buttons and cards

Animations should feel smooth, intentional, premium, and professional.

## Responsive Design

Design the complete experience for:

* Desktop
* Laptop
* Tablet
* Mobile

Maintain excellent spacing, typography, usability, and interaction quality across all screen sizes.

## Overall Goal

The final portfolio should immediately communicate:

**"This person can understand a problem, design a beautiful solution, and build the actual product using UI/UX design."**

The portfolio should be visually memorable, technically impressive, easy to navigate, and focused on converting visitors into clients or employers.
